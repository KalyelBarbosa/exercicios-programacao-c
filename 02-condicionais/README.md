# Exercícios de Estruturas Condicionais em C

Nesta pasta estão reunidos exercícios desenvolvidos durante as aulas de Linguagem de Programação, no curso de Sistemas de Informação da FHO.

## Conteúdos praticados

- Estruturas condicionais `if` e `else`
- Condições com `else if`
- Estrutura de seleção `switch`
- Operadores relacionais e lógicos
- Tomada de decisões em programas

## Objetivo

Praticar a construção de algoritmos capazes de tomar decisões com base em diferentes condições.
