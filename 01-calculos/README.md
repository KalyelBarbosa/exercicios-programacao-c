# Exercícios de Cálculos em C

Nesta pasta estão reunidos exercícios desenvolvidos durante as aulas de Linguagem de Programação, no curso de Sistemas de Informação da FHO.

## Conteúdos praticados

- Declaração e utilização de variáveis
- Tipos de dados `int`, `float` e `double`
- Operadores aritméticos (`+`, `-`, `*` e `/`)
- Entrada e saída de dados com `scanf` e `printf`
- Aplicação de fórmulas matemáticas
- Cálculos de áreas e outras operações numéricas

## Objetivo

Praticar os fundamentos da linguagem C por meio da construção de algoritmos que realizam cálculos matemáticos, utilizando variáveis, operadores aritméticos e entrada de dados fornecidos pelo usuário.
